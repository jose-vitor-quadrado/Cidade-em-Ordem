# Cidade em Ordem — Frontend (Angular 22)

Versão em Angular 22 do frontend do projeto (standalone, signals, zoneless, Signal Forms).

## Requisitos
- Node.js 22.22.3+, 24.15.0+ ou 26+ (exigência do Angular CLI 22)
- Backend rodando (por padrão em https://localhost:7119 — altere em `src/app/core/api.config.ts`)

## Executar
```bash
npm install
npm start          # http://localhost:4200  (painel: /admin)
npm run build      # gera dist/
npm test           # Vitest
```
