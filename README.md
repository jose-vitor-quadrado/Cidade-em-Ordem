# 🏙️ Cidade em Ordem

**Uma plataforma para registrar, consultar e acompanhar problemas urbanos.**

O **Cidade em Ordem** é um projeto acadêmico desenvolvido para a disciplina de **Linguagens de Programação I**, da faculdade **UNIRP**, como parte do aprendizado sobre desenvolvimento de APIs Web com .NET.

A aplicação busca facilitar o registro e o acompanhamento de problemas urbanos, incentivando a participação dos cidadãos na identificação de situações que precisam de atenção e contribuindo para a melhoria da cidade.

## ✨ Funcionalidades

### 📍 Registro de problemas urbanos

Permite que os cidadãos registrem ocorrências urbanas por meio de um formulário com os seguintes campos:

- **Descrição:** detalhamento do problema identificado.
- **Categoria:** classificação do tipo de ocorrência.
- **Prioridade percebida:** indicação da urgência do problema.
- **CEP:** código postal do local da ocorrência.
- **Rua / logradouro:** endereço onde o problema foi identificado.
- **Bairro:** bairro da ocorrência.
- **Cidade:** cidade onde o problema está localizado.
- **Estado (UF):** estado correspondente ao endereço.
- **Foto:** imagem opcional para auxiliar na identificação do problema.

O preenchimento do CEP também pode auxiliar na obtenção automática de informações do endereço.

### 🔎 Consulta de problemas

Permite consultar os problemas urbanos cadastrados e realizar buscas utilizando diferentes campos, facilitando a localização de ocorrências específicas.

### 🛠️ Administração de ocorrências

O sistema conta com uma área administrativa que permite ao administrador:

- Consultar os problemas cadastrados.
- Atualizar as informações de uma ocorrência.
- Excluir problemas registrados.

Essas funcionalidades permitem manter os registros atualizados e administrar as informações disponíveis na plataforma.

## 🖥️ Interface

A interface foi desenvolvida para facilitar o registro e a consulta de ocorrências, com formulários organizados e campos específicos para descrever o problema e informar sua localização.

## 🧰 Tecnologias utilizadas

### Frontend
- **HTML** — estruturação das páginas.
- **CSS** — estilização e layout da interface.
- **JavaScript** — lógica e interatividade da aplicação.

### Backend
- **.NET 10** — plataforma de desenvolvimento.
- **ASP.NET Core** — construção da API Web.
- **Entity Framework Core (EF Core)** — mapeamento objeto-relacional (ORM) e acesso aos dados.
- **SQLite** — banco de dados relacional utilizado para armazenar as informações.
